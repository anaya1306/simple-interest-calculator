# Simple Interest Calculator

A simple Bash-based calculator that computes simple interest based on the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The calculator takes the following inputs:

* Principal amount
* Rate of interest
* Time period

## Output

The calculator calculates and displays the simple interest based on the values entered by the user.

## Project File

* `simple-interest.sh` – Bash script that calculates simple interest.
